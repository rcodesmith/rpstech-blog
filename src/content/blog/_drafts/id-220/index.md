http://www.dyngeometry.com/web/WorldRegion.aspx Lets you select country, state/province, and generates GPolygon JavaScript code for the boundary. For larger regions (e.g. southwest U.S.), would have to edit polygon points manually.

KML overlay may be a better option. Here is a KML file of U.S. states: http://code.google.com/apis/kml/documentation/us\_states.kml

KML overlays: http://gwt.google.com/samples/hellomaps-1.1.0/HelloMaps.html#KML%20Overlays

See samples/hellomaps/src/com/google/gwt/maps/sample/hellomaps/client/KmlOverlayDemo.java demo within distribution.

Click handling: http://gwt.google.com/samples/hellomaps-1.1.0/HelloMaps.html#Click%20Handling

See samples/hellomaps/src/com/google/gwt/maps/sample/hellomaps/client/ClickDemo.java demo within distribution
