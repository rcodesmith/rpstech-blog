Wanted to give kudos to a handy little Java utility I started using: [jarexplorer](http://code.google.com/p/jar-explorer/). It's a Swing-based app that indexes the contents of jar files found in an entire directory structure, and lets you search for classes and files within those jar files. It's blazingly fast and also provides viewers to look into classes, text files, and images. Double click on the search results and the viewer comes up. Nice to see tools that do one thing and do it well.
