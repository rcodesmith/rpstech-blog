I've started using the [Mercurial](http://www.selenic.com/mercurial/wiki/) version control system lately and switched over some projects over to it from Subversion. Since Google Code doesn't yet support hosting Mercurial repositories, [pyAntTasks](http://code.google.com/p/pyanttasks/) has stayed on Subversion. Until now that is - I set up a Mercurial repository for pyAntTasks on [sharesource](http://sharesource.org/) [here](http://hg.sharesource.org/pyanttasks/). I'll also push out any new releases to Subversion on Google Code, so people can still use that as well.
