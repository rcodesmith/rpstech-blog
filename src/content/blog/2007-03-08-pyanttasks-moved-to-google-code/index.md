[pyAntTasks](http://code.google.com/p/pyanttasks/) is a set of Apache Ant tasks to work with Python code I created a while back. Debedb has added a [py-cover task](http://debedb.blogspot.com/2007/01/continuous-integration-with-code.html) to report on code coverage. I recently moved pyAntTasks over to Google code for hosting so it's easier for people to get the source.  
  
Getting set up on Google code was a breeze... Register your project, get Subversion access, check in the source, and upload the binary distribution. All in all it took about 5 minutes.
